# Skill: Akita-Evo 新手引导
# ID: system:tutorial_evo
# Description: 引导新手了解 Akita-Evo 的影子工作区、自愈进化和可视化功能。

## 目标
帮助用户通过一个实际的小任务，掌握 Akita-Evo 的三大核心特性。

## 引导流程

1.  **第一步：影子工作区体验**
    - 告诉用户：“我会帮你创建一个简单的测试文件，但别担心，我会在‘影子工作区’里进行。这样你的真实目录是绝对安全的。”
    - 使用 `write_file` 创建 `evo_test.py`，内容为 `print('Hello Akita-Evo')`。
    - 提醒用户：“你可以看到输出日志中提示路径已被重定向到 .openakita/shadow/ 目录下。”

2.  **第二步：自愈能力演示**
    - 故意修改 `evo_test.py` 引入一个语法错误（例如去掉引号）。
    - 告诉用户：“现在我故意制造了一个小错误，看我如何‘自愈’它。”
    - 运行 `run_shell` 执行脚本，报错后，展示如何通过分析日志并重新调用 `write_file` 修复。

3.  **第三步：视觉记忆展示**
    - 告诉用户：“干得不错！现在来看看我把这次‘学习经验’记在哪里了。”
    - 调用 `visualize_memory_graph` 工具。
    - 指引用户查看生成的 PNG 仪表盘。

## 使用建议
当用户询问“怎么开始？”、“Akita-Evo 是什么？”或“新手怎么用？”时，主动推荐此引导流程。
